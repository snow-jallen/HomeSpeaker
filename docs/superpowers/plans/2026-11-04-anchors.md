# Anchors Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace HomeSpeaker's anchors with per-person anchors, computed (not copied) daily expectations, and touch-friendly board / my-day / edit pages, then add a remote-HomeSpeaker source, an external feed with write-back, and iOS/watch clients.

**Architecture:** Pure domain rules (`AnchorRules`, `AnchorPeriods`) decide expected days, cell states and streaks. EF entities store people, anchors, active periods and logs. `IAnchorStore` is the one facade the Blazor pages and the REST API use; phase 1 implements it locally, phase 2 adds a remote implementation, phase 3 merges an external feed into the local one.

**Tech Stack:** .NET 10, ASP.NET Core minimal APIs, Blazor Server (glass components), EF Core SQLite, xUnit; SwiftUI (phase 4).

**Spec:** `docs/superpowers/specs/2026-11-04-anchors-design.md`

## Global Constraints

- Git: Jonathan runs all git commands. No commit steps; leave changes in the working tree.
- Debug builds treat warnings as errors; Meziantou MA0048 = one top-level type per file (server project); private fields camelCase without underscore; private methods camelCase like the surrounding files.
- All time via `TimeProvider`; "today" = `DateOnly.FromDateTime(TimeZoneInfo.ConvertTimeFromUtc(utcNow, timeProvider.LocalTimeZone))`.
- Everything stays behind `FeatureFlags.AnchorsEnabled` (`Features:Anchors=true`).
- Days bitmask: Sunday=1, Monday=2, … Saturday=64; 127 = every day (`1 << (int)DayOfWeek`).
- Slots: `morning|day|evening`. Cell states: `kept|missed|open|off|none|unknown`. JSON camelCase, dates `yyyy-MM-dd`, enums as lowercase strings.
- Anchor and person ids on the wire are strings (local int ids rendered as strings).
- Max board range 92 days; log PUT rejects dates more than 1 day after today (400).
- Anchor title ≤ 120 chars, person name ≤ 40 chars, non-blank.
- No auth on anchor pages or `/api/anchors/*`; `/settings` stays admin-gated.

## Review Focus

- Editing an anchor's days mid-history must leave past cells unchanged (pinned in Task 1 `ChangeDays_DoesNotAlterPastCells`).
- Retire then restore on the same day must not create a zero-length or overlapping period (Task 1 `RetireThenRestoreSameDay_LeavesOneOpenPeriod`).
- A tick on a day before the anchor existed shows `kept`, not an error (Task 4 `PutLog_OnDayOutsidePeriods_IsKeptBonus`).
- Server timezone near midnight: "today" follows `timeProvider.LocalTimeZone`, not UTC (Task 3 `Board_TodayUsesLocalZone`).
- Legacy DB with partial data (assignment but no daily rows, inactive definitions) migrates without throwing and is idempotent on second boot (Task 2 tests).

**Interfaces — Produces:**
- `static class DayMask { const int Every = 127; static bool Includes(int mask, DayOfWeek day); static int Of(params DayOfWeek[] days); }`
- `sealed record AnchorPeriod(DateOnly From, DateOnly? To, int Days)` (To exclusive; `Covers(DateOnly d)` = From<=d && (To is null || d<To); `IsScheduled(DateOnly d)` = Covers && DayMask.Includes).
- `static class AnchorPeriods`:
  - `IReadOnlyList<AnchorPeriod> Start(DateOnly today, int days)` → one open period.
  - `IReadOnlyList<AnchorPeriod> ChangeDays(IReadOnlyList<AnchorPeriod> periods, int days, DateOnly today)` — open period starting today → edited in place; open period starting earlier → closed at today, new open period from today; no open period → unchanged (days only matter while active).
  - `IReadOnlyList<AnchorPeriod> Retire(IReadOnlyList<AnchorPeriod> periods, DateOnly today)` — closes the open period at today; a period that would become empty (From == today) is removed.
  - `IReadOnlyList<AnchorPeriod> Restore(IReadOnlyList<AnchorPeriod> periods, DateOnly today)` — no-op if open; if the last period has To == today, reopen it (To = null); else append `(today, null, lastDays)`.
  - `bool IsActive(IReadOnlyList<AnchorPeriod> periods)`; `int CurrentDays(IReadOnlyList<AnchorPeriod> periods)` (open period's days, else last period's, else Every).
- `static class AnchorRules`:
  - `AnchorCell CellFor(IReadOnlyList<AnchorPeriod> periods, bool missingIsUnknown, DateOnly date, DateOnly today, bool done)` — done → Kept (even when not scheduled); not covered → None; covered but weekday not in days → Off; date == today → Open; date > today → None; past → missingIsUnknown ? Unknown : Missed.
  - `int Streak(IReadOnlyList<AnchorPeriod> periods, bool missingIsUnknown, IReadOnlySet<DateOnly> doneDates, DateOnly today)` — walk back from today to the earliest period From: Kept → +1; Missed → stop; Open/Off/None/Unknown → skip.
  - `int PersonStreak(Func<DateOnly, IReadOnlyList<AnchorCell>> cellsOn, DateOnly today, DateOnly earliest)` — a day counts if it has ≥1 Kept and every cell is Kept/Off/None/Unknown; today with any Open and no Missed is skipped; a day with no Kept and nothing Missed (all off/none/unknown) is skipped; any Missed stops.
